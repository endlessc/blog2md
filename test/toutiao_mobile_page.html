做开发的兄弟都知道，截取长代码或者完整的网页设计稿是刚需。

Mac 自带的 Shift + Command + 4 只能截当前屏幕，遇到长内容只能干瞪眼。市面上的 CleanShot X 确实强，但 29 美元的价格也确实劝退。Xnip 这种免费版又有水印，用起来总觉得膈应。

ScrollSnap 就是为了解决这个问题诞生的。它完全开源、免费，而且是用 Swift 原生写的，体积小到可以忽略不计。

核心功能：把“长截图”这件事做到极致

我试用了一下午，这几个功能真的深得我心：

1. 丝滑的滚动截图

这是它的杀手锏。选中区域，点击“Capture”，然后像平时浏览网页一样滚动，点“Save”，一张完整的长图就生成了。

它底层用了 macOS 最新的 ScreenCaptureKit，拼接速度快得离谱，几乎没有延迟。不管你是截几千行的代码，还是超长的落地页，它都能完美处理。

2. 原生级的交互体验

很多开源工具的 UI 都有一股“土味”，但 ScrollSnap 做得非常 Mac Native。

半透明的遮罩、圆角的菜单栏、流畅的动画，用起来感觉就像是系统自带的功能一样。这种细节的打磨，真的能看出作者的用心。

3. 贴心的缩略图菜单

截图完成后，左下角会弹出一个悬浮的缩略图（这点和系统截图很像）。

你可以直接把缩略图拖到微信、飞书里发送，或者右键选择保存、删除。这个细节真的太懂用户了，省去了去 Finder 找文件的麻烦。

技术揭秘：Swift + ScreenCaptureKit

作为一个技术博主，我特意扒了下它的源码。这项目是纯 Swift 写的，代码质量很高。

它抛弃了老旧的截图 API，直接上了 Apple 最新的 ScreenCaptureKit。这意味着它不仅性能更强，而且更省电，对系统资源的占用极低。

相比那些用 Electron 套壳的截图工具，ScrollSnap 的启动速度和响应速度简直是降维打击。对于想学习 macOS 应用开发，特别是想研究屏幕录制、图像处理的同学，这个项目绝对是教科书级别的。

怎么用？3步搞定

  1. 启动：打开 App，屏幕会出现遮罩。
  2. 选区：拖拽选择你要截图的区域。
  3. 滚动：点击 Capture，开始滚动内容，结束点 Save。

就这么简单，没有任何学习成本。

实战对比：它凭什么挑战付费软件？

我拉了个表格，把 ScrollSnap 和其他工具做了个对比：

  • Mac 自带：免费，但功能单一，无法截长图。
  • CleanShot X：功能最强，但贵（$29）。
  • Xnip：免费版有水印，订阅制。
  • ScrollSnap：免费、开源、无水印，专注长截图。

说实话，也不是完美的

用了半天，客观说一下它的缺点：

  1. 功能比较纯粹：它专注于截图，没有标注、马赛克、OCR 文字识别这些高级功能。如果你需要这些，可能还是得配合其他工具。
  2. 还在早期阶段：0.6K Star 说明它还很年轻，偶尔可能会遇到一些小 Bug，不过作者更新很勤快。

最后

如果你只是需要一个能截长图的工具，又不想花冤枉钱，ScrollSnap 绝对是你的首选。

它没有花里胡哨的功能，就是把“截图”这一件事做到了极致。免费、开源、原生体验，还要什么自行车？
